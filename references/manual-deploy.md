# 手动拖拽部署（agent 代打参考）

> 2026-11-03 在 TR-28（主线 17 章教学关，0 理智）实测通过的全链路。
> 用途：作业缺失/作业失效时的**手动兜底**——活动刚更新、作业站还没轴、
> 或者像模组任务这种"要求特定干员上场"的自定义条件关。

## 已验证的完整链路（adb 1920×1080）

```
1. 点选干员卡      input tap <卡片x> <卡片y>
   → 卡片抬起，左下弹出干员详情，地图上绿色可部署格高亮
2. swipe 拖到目标格  input swipe <卡x> <卡y> <格x> <格y> 500
   → 白色菱形范围 + 橙色朝向杆 = 部署预览态
3. 确认朝向         input swipe <格x> <格y> <格x> <格y-150> 300   （朝上为例）
   → 干员落地，费用扣除，剩余可放置 -1
4. 截图验收         干员立绘出现在格上即成功
```

实测数据（TR-28，米格鲁 18 费）：
- 部署前：剩余可放置 4、费用 42；部署后：3、24。数字变化即验收依据。
- swipe 时长 400~700ms 都能被识别；太短（<200ms）会被当成点击。
- **先点选再拖**比直接从栏里拖更稳（直接拖偶尔被当成滑动地图）。

## 节奏问题与对策（TL-1 三连败的教训）

agent 一轮操作 = 截图(2s) + 决策(1s) + 发送(1s) ≈ **5 秒**。
TL-1 这种 21 敌 3 血的开局扛不起 5 秒延迟。对策：

1. **选宽容的关练手/执行**：0 费教学关（TR-xx）、敌人慢的关、
   或者开场给足费用缓冲的关。TR-28 是完美实验场（0 理智无限重试）。
2. **开战后立即暂停**：暂停态可以部署，随时截图。暂停键 (1822,88)。
   注意截图偶发全黑（screencap 竞态），重试一次即可。
3. **预计算好落点再开战**：先看敌方情报/地图确定部署格，
   开战后按既定清单执行，减少中间决策。

## 教学关的对话干扰

TR 类教学关开场有强制对话，点 (700,60) 可推进，但**游戏会在
"等你执行教学动作"处停下来**（画面出现橙色箭头指引 + 高亮格），
此时对话点不掉、必须完成指定动作才能继续——正好是被验证的拖拽时机。

## 退出不亏

- **TR 教学关**：0 理智，放弃/打输都无损。
- **推演模式**（主线险地作战）：放弃返还全部理智。
- 普通关放弃：按完成度比例返还，仍建议在编队页就确认好再进。

## 模组任务批量流水线 v2（2026-11-03/04 二次实战：3 个模组任务全清）

**核心捷径（用户亲授 + 实测）：干员的模组任务面板里有「前往 >」按钮，
点了直接跳到目标关卡**——完全不用去乐章收录翻活动入口。整个流程：

```
大厅 → 干员(大按钮 1573,533) → 列表按「稀有度」排序(1467,60)
→ 点干员卡 → 模组卡(1677,847) → 模组页滚到锁定分支(swipe 1200,820→560)
→ 点「解锁」(≈1394,838) → 任务面板 → 点「前往 >」(904,532)
→ 直达关卡页 → run_stage.py <code> --file <作业.json>
```

### 作业 sourcing 与练度核对（血泪教训）

prts 搜「<关卡>+模组」基本都有专用作业，但**必须核对 skill_level 要求**：

| 作业 | 要求 | 结果 |
|---|---|---|
| 106129 乌尔比安Y模 BP-6 | skill_level **10 (=M3)** | 我方 S3 非 M3 → 编队照上、轴对不上 → 团灭×2 |
| 107671 同关 | skill_level 7 (M0) | 一把过 |

**优先选 skill_level≤7 的作业**；练度不足时用「忽略要求」也能编进去，
但轴的时序是对着作者练度写的，差一档就可能崩。未 3 星的关卡前几次
进攻是**演习**（免费）：结算页出现「理智返还」= 演习没扣体力，可以
无限重试换作业；出现「1.2 倍声望&龙门币奖励」= 真实通关。

### 改造（缺干员时替换 + 补技能）

- 技能次数类任务：给目标干员加 `"skill": N, "skill_usage": 1`（或照抄
  专用作业的 skill_usage=2），Deploy 后按 SP 回蓝节奏补显式 Skill 动作。
- 位置类条件（如"赫德雷在 [4,3]"）：**照抄专用作业作者的布点**，缺的
  队友用同定位干员替换（伊芙利特→澄闪、伊桑→红、速射手→能天使、
  奶盾→塞雷娅、医师→白面鸮），推荐等级 E1-50 的关我方 E2 随便碾。
- 落盘后 `run_stage.py <code> --file <绝对路径>.json`（相对路径会找错目录）。

### IW-7 赫德雷教训（2026-11-04 凌晨，5 局实录）

1. **通关 ≠ 任务完成**。第一局 40956 改造版真实通关（1.2×奖励），但
   面板显示 1/5 精英、0/1 沉沙——改造时占位干员【速射手】【医师】没删，
   MAA 自动用练度替补填位，替补把击杀全抢了。
2. **击杀归属任务必须"独享输出"**：只留目标干员一个有输出的，其余全
   换奶盾/医疗/快活（塞雷娅 S1、白面鸮、红不开技能）。
3. 但纯辅助队**打不过 IW-7 的限时波次**（v2 火神E2-20、v3 蛇屠箱队全部
   超时 MISSIONFAILED）。v4 把澄闪从 [2,4] 挪 [1,4] 削火力也败。
   结论：**IW-7 这类"击杀归属"关盲调 4 版不过就该停，交用户手操**
   （手操能控赫德雷 S2 只在沉沙显形时开）。
4. **失败现在全额返体**（2026 版本机制）：结算页「理智返还 21」，
   可以放心试错，不用演习。
5. **「数据已更新，即将进行同步」弹窗会锁死战斗启动**：MAA 干等 60s
   超时报「update deployment failed」。先点 ✓ 同步回主界面再重跑。
6. 编队界面结束后想再去同关：主界面/终端右下「**前往上一次作战**」
   横幅（活动 IW-7 乱局）一点直达，比模组面板前往还快。

### 模组状态三分法（用户实战经验，最可靠的判据）

干员详情页模组卡的**按钮形态**直接告诉你做不做：

| 形态 | 含义 | 动作 |
|---|---|---|
| 「解锁」按钮 | 未解锁 | 做任务；完成后**还得花材料**才能真解锁 |
| 向上双箭头 ↑↑ | 已解锁可升级 | 任务早就满了，只缺材料 |
| 无任何标志 | STAGE MAX 满级 | 完全不用碰 |

一个干员最多 3 个模组（如 CRU X / CRU Y），**逐分支判断**。2026-11-04 复核：
乌尔比安 CRU X = STAGE 2（双箭头，用户早解锁过）、锁定的是 CRU Y；
锏 SWO X 与黍 GUA X 已 STAGE 3 满级；赫德雷 CRU X 仍是「解锁」按钮
（任务 1/5、0/1 未完成）。

   TextChanged 不触发，作业列表保持空。maa_drive.set_path 已修（先清空
   再 SetValue，并等控件 enabled 后重试 3 次）。
