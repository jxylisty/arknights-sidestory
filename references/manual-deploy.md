# 手动拖拽部署（agent 代打参考）

> 2026-11-03 在 TR-28（主线 17 章教学关，0 理智）实测通过的全链路。
> 用途：作业缺失/作业失效时的**手动兜底**——活动刚更新、作业站还没轴、
> 或者像模组任务这种"要求特定干员上场"的自定义条件关。

## 已验证的完整链路（adb 1920×1080）

```
1. 点选干员卡      input tap <卡片x> <卡片y>
   → 卡片抬起，左下弹出干员详情，地图上绿色可部署格高亮
2. swipe 拖到目标格  input swipe <卡x> <卡y> <格x> <格y> 500
   → 白色菱形范围 + 橙色朝向杆 = 部署预览态
3. 确认朝向         input swipe <格x> <格y> <格x> <格y-150> 300   （朝上为例）
   → 干员落地，费用扣除，剩余可放置 -1
4. 截图验收         干员立绘出现在格上即成功
```

实测数据（TR-28，米格鲁 18 费）：
- 部署前：剩余可放置 4、费用 42；部署后：3、24。数字变化即验收依据。
- swipe 时长 400~700ms 都能被识别；太短（<200ms）会被当成点击。
- **先点选再拖**比直接从栏里拖更稳（直接拖偶尔被当成滑动地图）。

| 元素 | 坐标 |

## 节奏问题与对策（TL-1 三连败的教训）

agent 一轮操作 = 截图(2s) + 决策(1s) + 发送(1s) ≈ **5 秒**。
TL-1 这种 21 敌 3 血的开局扛不起 5 秒延迟。对策：

1. **选宽容的关练手/执行**：0 费教学关（TR-xx）、敌人慢的关、
   或者开场给足费用缓冲的关。TR-28 是完美实验场（0 理智无限重试）。
2. **开战后立即暂停**：暂停态可以部署，随时截图。暂停键 (1822,88)。
   注意截图偶发全黑（screencap 竞态），重试一次即可。
3. **预计算好落点再开战**：先看敌方情报/地图确定部署格，
   开战后按既定清单执行，减少中间决策。

## 教学关的对话干扰

TR 类教学关开场有强制对话，点 (700,60) 可推进，但**游戏会在
"等你执行教学动作"处停下来**（画面出现橙色箭头指引 + 高亮格），
此时对话点不掉、必须完成指定动作才能继续——正好是被验证的拖拽时机。

## 退出不亏

- **TR 教学关**：0 理智，放弃/打输都无损。
- **推演模式**（主线险地作战）：放弃返还全部理智。
- 普通关放弃：按完成度比例返还，仍建议在编队页就确认好再进。

## 模组任务自动化评估（凛御银灰 CSR-X 邀约为例）

任务结构（截图确认）：
- 任务 1：战斗中非助战凛御银灰累计使用 8 次「御敌的锋锐」（二技能）
- 任务 2：3 星通关扭曲 BI-7，必须编入非助战凛御银灰并上场，其他仅 7 人

可行性判断：
- **任务 1 好办**：任意低难关（如 TR-28 或已三星主线）带上凛御银灰，
  手动部署后反复开二技能。技能按钮在干员头顶，部署态下 tap 即可。
  8 次计数跨战斗累计，不必一场打满。
- **任务 2 难度中等**：BI-7 是常规主线支线（雪地关），难度不高，
  但"限 7 人 + 必须上场"意味着不能直接套现成 8 人作业。
  路线：搜 BI-7 现成作业 → 检查是否含凛御银灰 → 不含则手动替换
  （编队页点掉一个非核心，加凛御银灰），大概率作业轴仍能跑。
- 模组解锁本身还要 123/4 事迹、9/2 结晶等材料（截图左下），材料不够
  时自动化到"任务完成"为止即可，解锁那步是点按钮，纯 UI 流程。

## 局限（诚实边界）

- 只适合**非时序敏感**的场景。卡秒轴请用 MAA 作业。
- 朝向确认目前用"从格心向上滑"的固定动作，任意朝向需按箭头方向算偏移。
- 底部干员栏超过一屏时要先滚动，滚动后卡片坐标会变，需重新截图定位。
